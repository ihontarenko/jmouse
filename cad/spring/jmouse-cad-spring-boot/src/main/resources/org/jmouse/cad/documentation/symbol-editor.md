## How the editor works

The editor is used as every editor is:
- **Select** is the tool it rests in;
- **Esc** drops what is in hand, then goes back to Select, then lets go of what is chosen;
- messages are said in the corner of the window.

**Save** keeps the drawing and stays in the editor; **Auto** saves it on its own, as in every editor.

## Tools

| Tool | Key | What it does |
|---|---|---|
| Select | V | Chooses and moves; drag a shape's corners |
| Pick paint | I | Takes the paint of a shape, for the next one drawn |
| Line, Polyline, Arc | L, K, A | Lines |
| Box, Rounded, Ellipse, Circle, Triangle, Polygon | B, O, E, C, D, G | Closed shapes, filled or not |
| Text | T | Words on the drawing |
| Pin | P | A pin: where a wire meets the part |
| Distance, Angle | U, Y | Measures; adds nothing |
| Pan | H | Moves the view; the middle button does the same with any tool |

## The underlay

**View → Underlay** lays a picture under the drawing to draw over — a part photographed from above, for its portrait. It is kept
with the drawing.
