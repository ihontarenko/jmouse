# Fonts shipped with jmouse-stroke-fonts

## NewStroke — `newstroke.bene`

- Font: **NewStroke**, by Vovanium and the NewStroke developers — <http://vovanium.ru/sledy/newstroke/en>, released under
  CC0 («effectively equivalent to public domain»).
- File: the FontoBene conversion by the FontoBene developers, unchanged from <https://github.com/LibrePCB/fontobene-fonts>
  (`newstroke.bene`, header `license = CC0-1.0`) — the same file `@jmouse/stroke-fonts` ships.
- Licence: CC0 1.0 Universal — <http://creativecommons.org/publicdomain/zero/1.0/>.

Nothing here is taken from the copy compiled into KiCad's sources (`newstroke_font.cpp`, GPL-2.0+).
